# Architecture boundary migration — v0.296.0

This guide covers the additive import-boundary changes prepared by the July
2026 maintainability program. It does not announce publication; maintainers
must still run the release gate and publish through the documented process.

## Runtime root no longer aliases Core defaults

`@wrongstack/runtime` now exports only implementations physically owned by the
Runtime package: container/host composition, tool registration, vision,
clipboard, local-model probing, packs, and light-subagent assembly.

Import Core-owned defaults from their declared owner:

```ts
// Before: transitional pass-through
import { DefaultTokenCounter } from '@wrongstack/runtime';

// After
import { DefaultTokenCounter } from '@wrongstack/core/infrastructure';
```

## Observability has a declared Core subpath

Metrics sinks, health registry, Prometheus support, OTLP metrics export, and
event bridging remain Core-owned after the Runtime pilot. Use the focused
subpath instead of the compatibility root:

```ts
import {
  DefaultHealthRegistry,
  InMemoryMetricsSink,
  startMetricsServer,
  wireMetricsToEvents,
} from '@wrongstack/core/observability';
```

Erased contracts remain available from `@wrongstack/core/types`; `EventBus`
comes from `@wrongstack/core/kernel`; path contracts and helpers come from
`@wrongstack/core/utils`.

## Memory composition

Hosts should accept Core's `MemoryPort` and construct a backend through
`createSqliteMemoryPort(...)`. Optional SAGE operations use the typed
capability accessors. Direct construction of `SageStore` and
`SqliteSageStore` is deprecated and prohibited in new production code.

The JSONL compatibility port and legacy adapter remain available during the
compatibility window. Their eventual removal requires a later release with
zero production usage evidence.

## Repository ratchet

`architecture/core-api-policy.json` caps the number of files importing the Core
root. The cap may only move downward as files migrate to canonical subpaths.
The generated usage snapshot records every remaining repository consumer.
